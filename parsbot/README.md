# 🏰 پارس‌بات v3 — ناوگان چندرباته: سازنده‌ی قلعه‌های باشکوه + ربات‌های بقا و اکتشاف

ربات ماینکرفت فارسی (بر پایه Mineflayer) با داشبورد وب و کنسول. چند ربات هم‌زمان وارد یک سرور می‌شوند و **هر کدام یک نقش دارند**:

| نقش | کار |
|---|---|
| 🏗 `builder` (سازنده) | حالت creative؛ در ساخت گروهی شرکت می‌کند (اول زمین را هموار می‌کند، بعد قلعه می‌سازد) |
| ⛏ `survivor` (بقا) | حالت survival؛ می‌گردد، اکتشاف می‌کند، ابزار می‌سازد، ذوب می‌کند و هر چه بگویی پیدا می‌کند |
| 💤 `idle` (بیکار) | هیچ کاری نمی‌کند |

## نصب
```bash
cd mineflayer && npm install      # یک‌بار (mineflayer محلی)
cd ../parsbot && npm install
```

## اجرا
```bash
node src/index.js
```
مرورگر خودکار باز می‌شود و صفحه‌ی **«اتصال به سرور ماینکرفت»** را می‌بینی: آدرس سرور (مثلاً `Danial753.aternos.me:38644`)، اسم خودت در ماینکرفت (صاحب ربات‌ها)، تعداد ربات‌ها و اسم پایه را بنویس و **اتصال** را بزن. دفعه‌ی بعد همه‌چیز پر شده است. اگر مرورگر باز نشد، آدرسی که در ترمینال چاپ شده را باز کن. `--no-open` مرورگر را باز نمی‌کند.

بدون مرورگر (اختیاری): `node src/index.js --host Danial753.aternos.me --port 38644 --owner dsllo --bots 3 --username Bot`

داخل همان ترمینال هم می‌توانی دستور بنویسی (کنسول): `help`.

> برای عوض شدن حالت بازی (creative/survival) و برای تسطیح سریع با `/fill` ربات‌ها باید **OP** باشند: در کنسول سرور `op Bot` ... بدون OP هم کار می‌کنند (کندتر: ربات‌ها زمین را با دست می‌کنند).

## کنسول (ترمینال و داشبورد، یکسان)
```
role Bot2 survivor          ← نقش یک ربات (یا role all builder)
Bot2 get diamond 3          ← ربات بقا برود و بیاورد (الماس/آهن/غذا/ابزار...)
Bot2 find روستا             ← بگردد تا پیدا کند و مختصات بدهد
Bot3 explore 10             ← ۱۰ مرحله اکتشاف
build castle size=57 seed=7 style=azure     ← همه‌ی سازنده‌ها با هم
bots | goals | buildinfo | buildstop | stop | help
```
فارسی هم می‌شود: `Bot2 بیاور الماس 3` ، `Bot2 پیدا روستا` ، `نقش Bot2 بقا`.

## ساخت‌وساز 🏗 — هوشمند و باشکوه
۱. **نقشه‌برداری:** ربات‌ها پرواز می‌کنند و ارتفاع زمین، درخت و آب منطقه را اندازه می‌گیرند. اگر سایت بیشتر آب باشد هشدار می‌دهند.
۲. **تسطیح:** سطح زمین = میانه‌ی ارتفاع منطقه. تپه و درخت برداشته می‌شود، گودال پر می‌شود، لبه‌ها شیب ملایم می‌گیرند. با OP از `/fill` (خیلی سریع) و بدون OP با کندن/گذاشتن دستی.
۳. **ساخت:** لایه‌به‌لایه بین همه‌ی سازنده‌ها تقسیم می‌شود. پله، اسلب، در، فانوس، زنجیر، نردبان، آب (سطل) و ... با جهت درست گذاشته می‌شود. آویزها (فانوس/زنجیر) در انتها از بالا به پایین.

### نقشه‌ها
| نقشه | توضیح |
|---|---|
| `castle` | **قلعه‌ی باشکوه**: خندق با آب و پل متحرک، دیوار با کنگره و دریچه‌ی تیر و پشت‌بند، برج‌های گرد با سقف مخروطی و پرچم، دروازه‌خانه با نشان سلطنتی و دریچه‌ی آهنی، حیاط با خیابان سنگ‌فرش و چراغ، فواره، باغ و درخت و گل، دو ساختمان با سقف شیب‌دار، سالن بزرگ با گالری، لوستر، فرش قرمز و تخت پادشاه، و برج اصلی بلند |
| `fort` | دژ ساده و کوچک |
| `tower` / `wall` / `pyramid` | سازه‌های کوچک |

**خلاقیت:** هر `seed` یک قلعه‌ی یکتا می‌سازد (سبک، ارتفاع‌ها، تعداد برج، شیب سقف‌ها، درخت‌ها و گل‌ها). بدون seed تصادفی است و seed چاپ می‌شود تا بتوانی همان را دوباره بسازی.
سبک‌ها: `royal` (سنگ + بلوط تیره) | `gothic` (بلک‌استون + آجر نترا) | `azure` (کوارتز + پریسمارین آبی) | `sun` (ماسه‌سنگ) | `forest` (کبل‌استون + صنوبر).

پارامترها: `size=49..91` `seed=` `style=` `wallh=8..16` `at=x,z` (گوشه‌ی شمال‌غربی) `flatten=0` (بدون تسطیح) `ring=6` (پهنای شیب) `dry=1` (فقط پیش‌نمایش و مصالح) `force=1`.
قلعه‌ی ۵۷×۵۷ حدود ۳۰ هزار بلاک است؛ چهار ربات حدود ۱۵ تا ۲۰ دقیقه.

## حالت بقا و اکتشاف ⛏
`get <چیز> [تعداد]` ربات خودش تصمیم می‌گیرد: چوب بزند ← تخته ← میز کار ← کلنگ چوبی ← سنگ ← کلنگ سنگی ← کوره ← زغال ← آهن ← ذوب ← ... هر چه لازم باشد. اگر چیزی اطراف نبود اکتشاف می‌کند. اگر بمیرد دوباره برمی‌خیزد و ادامه می‌دهد.
`find <چیز>` می‌گردد و مختصات را می‌گوید (ماده‌ی معدنی، موجود، `village`/روستا).
واژه‌نامه‌ی فارسی: چوب، سنگ، زغال، آهن، طلا، الماس، غذا، گوشت، پشم، کوره، کلنگ، شمشیر، روستا، ...

## تنظیمات شخصی
`config.local.json` (در گیت نمی‌رود):
```json
{ "owner": "NameDanial", "ownerPassword": "رمز-قوی", "defaultRole": "builder", "dashboard": { "token": "توکن-ثابت" } }
```
- `owner` خالی و بدون رمز → دستورات حساس از چت کار نمی‌کنند (فقط داشبورد/کنسول).
- روی سرور آفلاین با `ownerPassword` داخل بازی پیام خصوصی بده: `/msg Bot login رمز`.

## چت داخل بازی
`!دستور` → ربات اصلی (★) | `!Bot2 دستور` → همان ربات | `!all دستور` → همه.

## امنیت
داشبورد فقط `127.0.0.1` با توکن اجباری؛ صاحب‌بودن از روی اسم جعل‌پذیر نیست؛ `say` هرگز `/دستور` نمی‌فرستد.

## محدودیت‌ها
- حساب مایکروسافت فقط یک ربات؛ چند ربات فقط روی سرور آفلاین/محلی.
- زمین‌های خیلی ناهموار یا دریا: ابتدا هشدار می‌دهد (`force=1` برای اجبار).
- ربات بقا عمق‌کاری/غار را با احتیاط ولی بدون تضمین انجام می‌دهد (لاوا کنار هدف رد می‌شود؛ ممکن است بمیرد و دوباره ادامه دهد).
- ماهیگیری و کشاورزی همان قبلی هستند.
